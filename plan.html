Hook Entry Point

Day 3 · ~2h · Lukas
  • 22
    Implement hook.py — the script Claude Code calls on every tool use: 
    import sys, json
from guardrail.policy import load_policy
from guardrail.matcher import extract_paths, matches_forbidden
from guardrail.logger import log_event

def main():
    payload = json.load(sys.stdin)
    tool_name = payload.get("tool_name")
    tool_input = payload.get("tool_input", {})

    policy = load_policy()
    paths = extract_paths(tool_name, tool_input)

    for path in paths:
        if matches_forbidden(path, policy):
            log_event(tool_name, path, "block", payload)
            print(f"[guardrail] BLOCKED: {path}")
            sys.exit(1)

    log_event(tool_name, paths, "allow", payload)
    sys.exit(0)
  • 23
    Implement extract_paths(tool_name, tool_input) → list[str]:
    • Read / Write / Edit: return tool_input["file_path"]
    • Bash: regex-extract path-like strings from tool_input["command"]
    • other tools: return []
  • 24
    Register the hook on the Pi in ~/.claude/settings.json: 
    "command": "cd ~/guardrail && uv run python -m guardrail.hook"
  • 25
    Manual test on the Pi: try to read a forbidden file via Claude Code → should be blocked

If Something Goes Wrong

  • 🔌
    Hook doesn't block Test with a standalone exit 1 script first. Check that the hook command path is absolute and that uv is in PATH on the Pi.
  • 🍓
    Claude Code won't install on Pi (ARM) Check uname -m — Pi 4/5 is aarch64 (supported). Pi 2/3 is armv7l — may not work. Use a Pi 4 or newer.
  • 🌐
    Pi not reachable Set a static IP or use pi.local hostname. Add to /etc/hosts on your dev machine if needed.
  • 📁
    Sandbox path issues Use absolute paths everywhere (/home/pi/sandbox/...). Avoid ~ in the policy on the Pi — it resolves differently depending on the user running the hook.
  • 🤔
    Claude Code "ignores" the policy The hook controls tool calls only — not what Claude thinks. The agent can reason about forbidden paths without triggering a violation. Only actual tool calls count.
  • ⏱
    No time for all experiments Skip condition D. Run A + B + C only — still a valid result that answers the core research question.
  • 🐢
    Slow inference on Pi Claude Code calls the Anthropic API remotely — the Pi only needs internet access, not a GPU. Performance depends on network, not hardware.
